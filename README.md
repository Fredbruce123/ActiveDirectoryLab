<h1> Active Directory Home Lab </h1>

 ### [YouTube Demonstration](https://youtu.be/7eJexJVCqJo)

<h2>Description</h2>
Active Directory Home Lab is a virtual environment built using VirtualBox to simulate a real-world corporate network. The lab typically includes a Windows Server configured as an Active Directory Domain Controller and one or more Windows client machines joined to the domain.
<br />


<h2>Languages and Utilities Used</h2>

- <b>PowerShell</b> 
- <b>Diskpart</b>

<h2>Environments Used </h2>

- <b>Windows 10</b> (21H2)
- <b>Server 2019 </b> (21H2)
